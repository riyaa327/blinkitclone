# Blinkit Website Clone  Developed a responsive **Blinkit website clone** using **HTML, CSS, and JavaScript** that replicates the look and feel of the original grocery delivery platform. The project features a clean and modern user interface with responsive layouts, interactive navigation, product sections, banners.
Technologies Used:

HTML5
CSS3
JavaScript (ES6)

Key Features:

Responsive design for desktop and mobile devices
Interactive navigation bar
Product listing and category sections
Search bar UI
Shopping cart interface
Modern animations and hover effects
Clean and user-friendly layout

This project was built to strengthen my skills.
